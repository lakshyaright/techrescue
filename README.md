# TechRescue

A responsive static website for a device repair and IT support business.

## Files

- `index.html` - page structure and content
- `styles.css` - responsive visual design
- `script.js` - mobile navigation, sticky header, and form feedback
- `assets/techrescue-hero.jpg` - generated hero image

## Run Locally

Open `index.html` in a browser. No build step or dependencies are required.

## Deploy

This project can be deployed directly with GitHub Pages from the `main` branch.
